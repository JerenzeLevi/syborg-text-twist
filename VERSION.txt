SYBORG Text Twist — Version History

## 1.5
- Added missing common words to the dictionary (axe, orb, orbs) so they're
  no longer silently rejected as invalid finds.

## 1.4
- Added new technical vocabulary across Software Engineering, Cybersecurity,
  Networking, AI & Data Science, Embedded Systems, Visual Graphics, Computer
  Animation, Object Oriented Programming, Programming Languages, and BLIS &
  IS Concepts — every new term is in the guessable dictionary so none of
  them are silently rejected as invalid finds.

## 1.3
- Expanded Networking with real tools/devices (crimp, crossover, patch,
  splice, punch, ethernet, modem, hub, bridge, repeater, coaxial, fiber,
  wireless, networking, topology, tester, stripper, antenna, relay, node,
  mesh, ping, terminate, conduit) — every new term is in the guessable
  dictionary so none of them are silently rejected as invalid finds.
- Added two new categories: Object Oriented Programming (instance,
  inheritance, polymorphism, encapsulation, abstraction, constructor,
  destructor, superclass, subclass, interface, override, singleton,
  composition, class, object, method, attribute) and Programming Languages
  (Python, Java, JavaScript, Kotlin, Swift, Go, Rust, Ruby, Scala, Perl,
  COBOL, Fortran, Haskell, Pascal, Prolog, MATLAB, C#, TypeScript, PHP,
  Lisp). "Instance" and "Inheritance" moved out of Software Engineering
  into the new OOP category since that's where they actually belong.
- Clearing a round now resets the clock to a full 120s and clears Second
  Wind (ready/used) for the next puzzle, instead of carrying the leftover
  time forward. The "Wind Immunity" streak tracker (rounds cleared without
  needing Second Wind) is unaffected — an unused bank still counts.
- Enforced a 5-letter minimum on every technical vocabulary word (no more
  3-4 letter entries); removed short-form language names (Java, PHP, Rust,
  Ruby, Perl, Lisp) and dropped the last two 4-letter leftovers from
  earlier categories (Gimp, Maya) to match.

## 1.2
- Rebuilt the word dictionary (3,963 → 25,912 words) from a proper
  common-English-word corpus instead of a length-capped, overly strict
  frequency filter. Fixes valid guesses being rejected as "not a real
  word" and timer-penalized (e.g. "process"), and short common words
  missing from puzzles entirely (e.g. "reek", "elk").
- Raised the dictionary's word-length ceiling from 6 to 8 letters to match
  Technical Mode's longest base words. Previously any technical base word
  of 7-8 letters (e.g. "protocol", "bandwidth", "gateway", "endpoint")
  could never appear as a findable solution — including as the round's
  own final word — because the dictionary structurally excluded words
  that long. Every technical base word is now verified to include itself
  among its own solutions.
- Folded standard technical vocabulary (runtime, boolean, backend,
  frontend, dataset, captcha, keyframe, etc.) into the guessable
  dictionary so these terms are valid whenever they're spelled out from
  the letters on screen, not just recognized as round-starting words.
- Added a profanity filter to the dictionary build step — the previous
  raw word source included slurs and obscenities that were reachable as
  valid guesses.
- Kept brand/product names used only as Technical Mode base words
  (Pixar, InDesign, Lightroom) out of the guessable dictionary, since
  they aren't standard English words.

## 1.1
- Added new categories: Visual Graphics and Computer Animation (technical
  terms + common industry tools like Photoshop, Illustrator, Blender, Maya).
- Fixed missing common dictionary words that caused valid guesses to be
  rejected (e.g. "trained", "critic", "scum", "buff").
- Audited existing technical base words to ensure each has enough findable
  sub-words for Technical Mode.

## 1.0
- Initial release.
